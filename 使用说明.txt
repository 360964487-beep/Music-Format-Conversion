轻转 v0.2.0 — Windows 本地音频转换

使用方法
1. 将整个文件夹保留在一起，双击“轻转.exe”。无需安装 Python 或开发工具。
2. 拖入文件 / 文件夹，或点击“添加文件”。支持 NCM、FLAC、MP3、LRC。
3. 选择输出音质，点击“开始转换”。默认输出至原文件所在目录下的 MP3 文件夹。
4. 完成后点击“打开输出”。如果输入来自多个目录，该按钮打开最后完成歌曲的输出目录。

功能说明
- NCM：解析封装；内部是 MP3 时直接提取并保留原码率，内部是 FLAC 时转码。
- FLAC：按所选的 128 / 192 / 256 / 320 kbps 转为 MP3。
- MP3：直接复制音频流，不会升码率或进行二次压缩。
- 尽量保留现有的标题、歌手、专辑和嵌入封面；不联网补充缺失封面。
- 不删除源文件；输出重名时自动增加编号。
- 失败项不会阻塞后续歌曲。双击失败行查看完整错误，再点击“重试未完成”。
- 点击“取消”终止当前任务并清理未完成文件；已完成文件保留。
- 鼠标移到文件行可查看完整路径。所有按钮支持 Tab 导航。

环境与体积
适用于 Windows 10 / 11 64 位，使用 Windows 自带 .NET Framework 4.x。
主程序约 27 KB。完整离线版附带 FFmpeg，转码组件约 100 MB。
不要单独移动 EXE；src/Main.xaml 和 bin/ffmpeg.exe 是运行时所需文件。
本程序不要求联网，转换过程不上传音乐文件。

已验证与限制
已用生成的测试音频及 NCM 封装验证转换、中文与空格路径、重名处理、
元数据与封面、取消清理，以及真实窗口启动/退出。
尚未使用用户实际下载的 NCM 文件验证，不能保证兼容所有客户端版本与封装变体。
可先转换少量实际文件检查效果。损坏或不支持的文件会显示错误。
大量文件夹的导入阶段可能短暂等待；转码阶段在后台执行。

开发与依赖
源码：src/App.cs、src/Main.xaml。
重新编译：使用 PowerShell 执行 src/build.ps1。
格式兼容性参考：https://github.com/taurusxin/ncmdump
FFmpeg 下载来源：https://www.gyan.dev/ffmpeg/builds/
FFmpeg 为独立外部组件；许可证与构建配置见 bin/FFmpeg-LICENSE.txt、FFmpeg-BUILD.txt。
本包 FFmpeg 版本为 9.0.2；对应源代码见 FFmpeg-BUILD.txt 内的 Source Code 链接。

主窗口底部的「保存目录」可通过「选择目录」修改。音频转换和视频下载使用同一设置，退出后会记住目录。新版设置保存在 %LOCALAPPDATA%\QingZhuan。
需要桌面图标时，请在最终存放目录中双击「创建桌面快捷方式.cmd」。

视频下载（Windows）
打开「视频下载」，粘贴 B 站或抖音视频分享链接，使用主窗口设置的保存目录，点击「下载 MP4」。首次需要从 yt-dlp 官方 GitHub 获取组件。抖音要求验证时，可选择仅包含抖音站点的 Netscape 格式 Cookie 文本。
